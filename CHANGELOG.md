# Changelog

What changed in each version of Better-Walls. The newest version is at the top.

When you release, add a `## vX.Y.Z` section here before you push the tag. The
release workflow copies that section into the GitHub release notes.

## v1.0.1

### Fixed

- The main window now opens on top of other windows. Before, it could open
  behind whatever you clicked while the app was starting.
- Windows Defender is less likely to flag the exe as malware. The exe is built
  with a freshly compiled launcher and no extra compression.

### Changed

- The exe's Properties → Details now show the app name, description and version.
